Notable Gaps

Related Directories

Each of these covers one vertical. This page attempts the cross-section — commons-oriented tech across all categories, with gap analysis. Use them together.

Makerspaces

Australian Makerspace Directory

Interactive map of makerspaces, hackerspaces, and community workshops. Filter by equipment and features. The most comprehensive maker-only directory.

Makerspaces

Core Electronics — Makerspaces

Community-driven makerspace finder from the Newcastle hardware retailer. Map-based, equipment-focused. Hosts the TTN Newcastle meetup.

Open Source

Linux Australia — LUGs

Peak body for open-source in Australasia. Lists Linux User Groups by state plus a hackerspaces page linking to the Hackerspaces Wiki and mailing list.

Tech Meetups

Tech Groups

Aggregator for tech meetups, conferences, and events across Australian cities. Broad and uncurated — every React meetup and AWS user group alongside everything else.

Startup Ecosystem

Atrium — Australian Tech Communities

100+ communities, startup hubs, accelerators, co-working spaces, and founder networks. VC/growth-oriented rather than commons.

Civic Tech

Civic Tech Field Guide — Australia

Part of a global inventory of 8,000+ civic tech projects. Lists tools and organisations (OpenAustralia, Planning Alerts, NationalMap) rather than meetup communities.

Civic Tech

OpenAustralia Foundation

Builds free, open-source civic tech — Planning Alerts (198k+ development applications), They Vote For You, Right to Know (FOI requests). Relies on donations.

Radio

WIA — Club Directory

Wireless Institute of Australia (est. 1910) — the world's oldest national amateur radio society. Lists every affiliated club by state. Comprehensive for radio, nothing else.

Mesh & Wireless

wireless.org.au — Community Networks

Australian community wireless networks — Meshtastic, LoRaWAN, legacy mesh. Groups by state, Discord links. Also covers Meshtastic AU specifically.

Mesh & Wireless

MeshMap.me — The Mesh Directory

Global directory of LoRa mesh organisations, groups, and clubs — Meshtastic, MeshCore, Reticulum, and LoRa radio mesh technology.

Repair & Reuse

Repair Cafés & Fix-It — Australia Map

Community-maintained Google Map of 100+ repair events nationally. Drop-in sessions, tool libraries, electronics reuse hubs.

Repair & Reuse

Australian Design Centre — Repair Map

Sydney-focused repair community map. Shows the vibrant repair ecosystem around Sydney — cafés, mending groups, reuse centres.

Startup Mapping

Techboard — Startup + Tech Mapping

National startup and tech mapping project. Originally WA-focused, now expanded nationally. VC/growth lens — complements but doesn't overlap commons tech.
